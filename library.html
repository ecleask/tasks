Connect your sheet

To read your library, set the sheet to “Anyone with the link can view” under Share in Google Sheets, then paste its link below. To add books and change their status from this page, you also need the write link described under the setup steps.

Set up saving to your sheet
  1. In your Reading Dashboard sheet, choose Extensions, then Apps Script.
  2. Delete the starter code and paste in the contents of reading-ledger-apps-script.gs. If you want a passcode, type one into the PASSCODE line. Save.
  3. Choose Deploy, then New deployment, then the Web app type. Set Execute as to “Me” and Who has access to “Anyone”. Deploy, and approve the permissions Google asks for.
  4. Copy the Web app link, which ends in /exec, into the write link field below. Add the same passcode if you set one.

Anyone who has the write link can add rows to your sheet, so keep it private and use a passcode.
